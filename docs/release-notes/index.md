# Release Notes

This page lists all Linkiir Grid releases in reverse chronological order. Each entry includes new features, improvements, and bug fixes for that version.

Linkiir Grid uses [semantic versioning](https://semver.org/) (`major.minor.patch`):

- **Major** — breaking changes requiring migration
- **Minor** — new features and improvements
- **Patch** — bug fixes to an existing release
